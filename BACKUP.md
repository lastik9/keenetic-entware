# Бэкап / восстановление / клон флешки Keenetic

Снятие образа **уже готовой** USB-флешки роутера (Entware/XKeen) в файл `.kbak`,
разворачивание обратно и клонирование на другую флешку.

> Это про **резервную копию** рабочей флешки. Если нужно подготовить **чистую** флешку
> под Entware с нуля — см. [README](README.md), раздел «Подготовка флешки».

Копируется только **занятое** место файловой системы (`e2image`), поэтому образ маленький,
а снятие и запись — быстрые. Формат `.kbak` (tar.gz из `mbr.bin` + `opkg.e2img` + `meta.txt`)
**одинаков на macOS, Linux и Windows** — образ, снятый на одной ОС, разворачивается на другой.

| Скрипт | Платформа | Что делает |
|---|---|---|
| `backup.ps1` | Windows 10/11 | Обёртка. Поднимает WSL2, пробрасывает флешку, внутри запускает `backup-linux.sh`. |
| `backup-linux.sh` | Linux и WSL | Рабочий скрипт: делает образ / пишет образ. Единый источник правды. |

**Проверка целостности файлов** (необязательно). Контрольные суммы SHA-256:

```
backup-linux.sh : 490F62A9BC8035703AA4F63E0FA141E6F43AF8FDE8FCA904EC6A8E588261D07E
backup.ps1      : 245354C30C8BAFDB218EACCC082C4E4D7EEC8100ACB824A15F28F45420871941
```

Сверить: `Get-FileHash <файл> -Algorithm SHA256` (Windows) или `sha256sum <файл>` (Linux).
Не совпало — скачай файл заново из репозитория.

## Windows

`backup.ps1` сам ничего не пишет на диск: он поднимает **WSL2**, пробрасывает туда флешку
через `usbipd-win` и запускает внутри `backup-linux.sh` (тот же скрипт, что и на нативном Linux).

### Что будет установлено на компьютер

При первом запуске обёртка доустанавливает недостающее:

1. **WSL2 + Ubuntu** — подсистема Linux внутри Windows.
2. **usbipd-win** — проброс USB в WSL (ставится через `winget`).
3. **Пакеты `e2fsprogs` / `util-linux`** внутри Ubuntu (через `apt`, нужен интернет
   только в первый раз; дальше — офлайн).
4. **Сам `backup-linux.sh`** копируется внутрь Ubuntu в `/root/`.

Требования: Windows 10/11 x64, права администратора (запросит через UAC),
включённая виртуализация в BIOS/UEFI.

### Установка (первый запуск на чистой машине)

Один раз; на чистой Windows потребуется 1–2 перезагрузки — это нормально, скрипт подскажет.

**0. Виртуализация в BIOS/UEFI.** Включить `Intel VT-x` / `Intel Virtualization Technology`,
либо `AMD-V` / `SVM Mode`. Без неё WSL2 не поднимется.

**1. Скачать два файла в одну папку:** [`backup.ps1`](backup.ps1) и [`backup-linux.sh`](backup-linux.sh) (на странице файла — кнопка **«Download raw file»** справа сверху). Держать рядом удобно —
тогда обёртка возьмёт локальный `backup-linux.sh` и не будет качать его из сети.

**2. Установить WSL** (если ещё нет) — PowerShell **от администратора**:

```powershell
wsl --install -d Ubuntu
```

Перезагрузиться. Ubuntu попросит придумать **логин и пароль** (нужны только внутри Linux).
Если WSL уже стоит — сразу к шагу 3.

**3. Запустить обёртку** — правый клик по `backup.ps1` → **«Выполнить с помощью PowerShell»**,
либо из папки со скриптом:

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1
```

При первом запуске обёртка поставит **usbipd-win** и **попросит перезагрузиться** — так и надо:
свежая служба usbipd заработает только после ребута. **Перезагрузиться и запустить снова.**

> **Про интернет в WSL.** Если DNS перехвачен VPN/прокси/роутером, обёртка предложит
> прописать в WSL публичный DNS (1.1.1.1 + 77.88.8.8). Это меняет настройки **только внутри WSL**,
> Windows не трогает. После установки пакетов интернет не нужен.

### Самый простой способ — меню (бэкап, restore и клон в одном месте)

Вставь флешку, затем **правый клик по `backup.ps1` → «Выполнить с помощью PowerShell»**
(без всяких параметров). Скрипт запросит права администратора и покажет **меню**:

```
Что сделать?
  1) backup  - снять образ флешки в файл
  2) restore - записать образ из файла на флешку
  3) clone   - снять образ и сразу залить на другую флешку
Номер (1/2/3):
```

Дальше просто выбирай цифру: **1** — снять бэкап, **2** — восстановить, **3** — клонировать.
Ничего в командной строке набирать не нужно. Разделы ниже описывают, что происходит
в каждом пункте.

> Если правый клик не показывает «Выполнить с помощью PowerShell», открой PowerShell
> **от администратора**, перейди в папку со скриптом и запусти его без параметров:
> ```powershell
> cd "путь\к\папке"
> powershell -ExecutionPolicy Bypass -File .\backup.ps1
> ```
> Меню будет то же самое.

### Снять бэкап (Windows)

Пункт **1** в меню (или сразу, минуя меню):

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1 -Mode backup
```

Выбрать флешку из списка (обёртка покажет модель и размер). Источник **не стирается**.
Готовый `keenetic-backup-ГГГГММДД-ЧЧММСС.kbak` сохранится рядом со скриптом
(или в папке из `-OutDir`).

Флаги: `-NoShrink` — не ужимать ФС (образ крупнее, аварийный режим);
`-DryRun` — холостой прогон, на диск ничего не пишется.

### Восстановить (Windows)

> **Флешка при restore стирается полностью.**

Пункт **2** в меню (или сразу, минуя меню):

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1 -Mode restore
```

Либо с конкретным файлом:

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1 -Mode restore -InFile "C:\путь\образ.kbak"
```

Без `-InFile` обёртка покажет список `.kbak` рядом со скриптом. Выбрать **целевую флешку**,
подтвердить стирание вводом **`YES`** (заглавными — защита от случайного диска).

> Целевая флешка должна быть **не меньше** исходной. Не поместится — скрипт откажет
> **до** стирания, флешка останется цела.

### Клон (Windows)

> **Целевая флешка стирается полностью.**

Пункт **3** в меню (или сразу, минуя меню):

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1 -Mode clone
```

1. **Источник** — вставить исходную флешку, выбрать (не стирается). Обёртка снимет образ в `C:\Temp`.
2. Обёртка попросит подготовить цель: **один порт** — вынуть исходную, вставить целевую, Enter;
   **два порта** — на след. шаге выбрать именно **целевую** (не перепутать!).
3. **Цель** — выбрать целевую флешку, подтвердить вводом **`YES`**.

Образ клона **не удаляется** — остаётся в `C:\Temp\clone-*.kbak` как страховка;
обёртка покажет путь и команду для повторного разворота.

## Linux (нативно)

На нативном Linux `backup-linux.sh` запускается напрямую, без обёртки. Здесь `clone` видит
обе флешки одновременно (в отличие от WSL). Нужны `sudo` и пакеты `e2fsprogs` / `util-linux`
(на Debian/Ubuntu скрипт доставит их сам через `apt`).

Скачать и запустить меню:

```
curl -fsSLO https://raw.githubusercontent.com/lastik9/keenetic-entware/main/backup-linux.sh
sudo bash backup-linux.sh
```

Или сразу в нужном режиме:

```
sudo bash backup-linux.sh backup            # снять образ
sudo bash backup-linux.sh restore файл.kbak # развернуть образ (СТИРАЕТ флешку)
sudo bash backup-linux.sh clone             # снять и сразу залить на другую флешку
```

Переменные окружения (для автоматизации / опытных пользователей):
- `DEV=/dev/sdX` — задать устройство, пропустить интерактивный выбор;
- `ASSUME_YES=1` — не переспрашивать подтверждение устройства;
- `KBAK_OUT=путь` — куда положить `.kbak` при backup;
- `DRY_RUN=1` — ничего не писать на диск;
- `NO_SHRINK=1` — не ужимать ФС перед снятием образа.

> `restore` затирает swap-раздел; сигнатуру и метку `SWAP` затем ставит `router-setup.sh`
> уже на роутере (пункт «Только swap»). Подробнее — в [README](README.md).

## Если что-то пошло не так

**«Не найден wsl.exe»** — WSL не установлен, вернись к шагу 2 установки (Windows).

**Обёртка просит перезагрузку после usbipd** — это обязательно, перезагрузись и запусти снова.

**`tcp connect` / «A firewall appears to be blocking the connection… TCP port 3240»** — фаервол
режет соединение WSL→хост на порт **3240**: штатное правило usbipd (область `LocalSubnet`) не
покрывает NAT-подсеть WSL. Флешке ничего не грозит — attach просто не проходит. Добавь правило
(PowerShell **от администратора**) и повтори:

```powershell
New-NetFirewallRule -DisplayName "usbipd WSL 3240" -Direction Inbound `
  -Action Allow -Protocol TCP -LocalPort 3240 -RemoteAddress 172.16.0.0/12 -Profile Any
```

Если и после этого не проходит — разреши входящий `TCP 3240` в стороннем антивирусе/фаерволе
(Kaspersky, ESET и т.п.), он игнорирует правила Windows.

**«Флешка не появилась в WSL»** — смотри текст ошибки usbipd в логе выше; если явных ошибок нет,
передёрни флешку/USB-порт и повтори.

**Нет интернета в WSL при первом запуске** — пакеты ставятся из сети один раз; согласись на
предложение прописать DNS в WSL либо подключи интернет и повтори.

**Флешку опознавай по размеру/модели, а не по букве** — буквы и номера могут «уезжать»
между запусками; при выборе обёртка показывает модель и размер.

## Удаление инструмента с компьютера (Windows)

Убрать всё, что поставила обёртка. Разделы независимы. Все команды — **PowerShell от администратора**.

**1. Удалить usbipd-win:**

```powershell
winget uninstall --exact --id dorssel.usbipd-win
```

**2. Проверить, что флешка не осталась «расшаренной»** (до удаления usbipd):

```powershell
usbipd list
```

Если у флешки в колонке STATE стоит `Shared` — снять по её BUSID (например `2-3`):

```powershell
usbipd unbind --busid 2-3
```

**3. Удалить Ubuntu целиком** — заодно убирает скопированный скрипт, пакеты и правку DNS
(всё это жило внутри Ubuntu):

```powershell
wsl --list --verbose          # посмотреть список
wsl --unregister Ubuntu       # БЕЗВОЗВРАТНО удаляет все данные внутри
```

> Если Ubuntu нужна для другого — **не удаляй целиком**, а убери только следы:
> ```powershell
> wsl -d Ubuntu -u root -- rm -f /root/backup-linux.sh
> ```
> Пакет `util-linux` — базовый системный, в Ubuntu он и так есть с завода; без нужды
> его удалять не стоит. Если правился DNS и хочешь вернуть авто-DNS:
> ```powershell
> wsl -d Ubuntu -u root -- rm -f /etc/wsl.conf
> wsl --shutdown
> ```

**4. Удалить саму WSL** (только если не нужна больше ни для чего):

```powershell
dism.exe /online /disable-feature /featurename:VirtualMachinePlatform /norestart
dism.exe /online /disable-feature /featurename:Microsoft-Windows-Subsystem-Linux /norestart
```

Затем перезагрузиться.

**5. Временные файлы** обёртки (не твои бэкапы!):

```powershell
Remove-Item C:\Temp\restore-*.kbak, C:\Temp\clone-*.kbak -ErrorAction SilentlyContinue
```

Сохранённые `keenetic-backup-*.kbak` — это твои резервные копии, удаляй только если не нужны.
Сами `backup.ps1` / `backup-linux.sh` — обычные файлы, удали вручную.

> На нативном Linux «устанавливать» нечего: скрипт лишь использует системные `e2fsprogs`/`util-linux`.
> Убрать — просто удалить файл `backup-linux.sh`; при желании `sudo apt-get remove e2fsprogs`
> (только если пакет больше нигде не нужен).
